# MONO

白黒を基調にした、シンプルな個人管理アプリです。右側の丸いアイコンでtask&routineとhealthを切り替えられます。

## 機能

- TODAY / NEXT 7 DAYS / LATER のタスク管理（明日から7日後までがNEXT 7 DAYS。8日後以降と期限なしはLATER）
- グループ別の色付きマーカーと、GROUPSからの色変更
- 四角いチェックボタンで即時完了
- 完了タスクをHANGARに3日間保持
- HANGARから未完了へ復帰
- タスクごとのメモ保存とホバー表示
- ルーティーンの追加・編集・削除
- 7日間のルーティーン履歴
- 移動できるタスク追加・メモ編集ウィンドウ
- health：起床日ごとの就寝・起床時刻と睡眠時間のバー表示
- 月曜始まりの週平均（記録した日だけで計算、7時間未満は赤・7時間以上は青）
- 終了した週は日付と平均睡眠時間だけをアーカイブし、日別の詳細は保持しません

## 使い方

公開版は [MONO](https://goldfishstar0055.github.io/Chatgpt/) から使用できます。`index.html`を直接ブラウザで開くこともできます。外部ライブラリを読み込まない単一HTMLです。タスク、ルーティーン、グループの色、睡眠記録はそのブラウザのローカルストレージに保存され、端末間では同期されません。

healthでは起床した日の行に就寝・起床時刻を入力し、✓で保存します。深夜をまたぐ睡眠にも対応します。両方の時刻を空にして保存すると、その日の記録を取り消せます。未入力日は平均から除外されます。日付が変わると週の切り替えとアーカイブを自動で行います。

## GitHub Pages

`main`への更新は `.github/workflows/pages.yml` により自動でデプロイされます。PagesのSourceは **GitHub Actions** に設定されています。
